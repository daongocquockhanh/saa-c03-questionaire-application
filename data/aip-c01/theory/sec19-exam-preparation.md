## Section 19: Exam Preparation

### Study resources
- AWS Skill Builder "Standard Exam Prep Plan" — Amazon's own training resources, free tier likely sufficient
- "Official Practice Question Set" — 20-question practice test (free)
- Subscription Skill Builder — includes full-length practice exam
- Course's own practice exam — included in this Sundog/Datacumulus course
- Skill Builder learning plan URL: https://skillbuilder.aws/learning-plan/9VXVGYT38G/
- Official AWS Exam Guide PDF — AWS-Certified-Generative-AI-Developer-Pro_Exam-Guide.pdf (d1.awsstatic.com)

### Exam logistics
- Exam: AWS Certified Generative AI Developer - Professional (AIP-C01)
- Duration: 3 hours (170 minutes technically); most finish in ~2 hours
- Question count: 75 scored (85 during beta)
- Consult official Exam Guide PDF for passing score

### Tips
- Free AWS resources likely enough — start there before paying
- Use the Standard Exam Prep Plan on Skill Builder as backbone
- Do the Official Practice Question Set
- Take the subscription full-length practice exam if available
- Take the course's included practice exam
- Read the official Exam Guide PDF end-to-end
- Take the AWS Certified AI Practitioner exam first before attempting this Professional-level cert
- Don't rush — understand what each question is optimizing for and its requirements
- Sleep well, eat, bathroom before entering
